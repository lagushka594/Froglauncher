🐸 FrogLauncher

Удобный лаунчер для Minecraft на WPF (.NET 8) — всё нужное в одном месте, без лишней возни 🎮
✨ Что умеет

    📦 Сборки под рукой — создавайте и переключайте инстансы Minecraft в пару кликов

    🔍 Поиск модов — интеграция с Modrinth и CurseForge прямо в лаунчере

    ⚙️ Все загрузчики — Forge, Fabric, Quilt и NeoForge

    ⬇️ Умная загрузка — версии, библиотеки и ассеты качаются автоматически

    ☕ Автоподбор Java — лаунчер сам находит подходящую JDK

    🚀 Быстрый запуск — один клик, и вы в игре

    🎨 Приятный интерфейс — тёмная тема, плавные анимации, ничего лишнего

💻 Платформа

Windows 10/11 x64 • .NET 8 • Self-contained сборка (ничего доустанавливать не нужно)
📥 Установка

Скачайте FrogLauncherSetup.exe из раздела Releases и запустите — установщик всё сделает сам 🐸

Сделано с любовью к Minecraft и лягушкам 💚
