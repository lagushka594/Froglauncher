# 🐸 FrogLauncher

Удобный лаунчер для Minecraft на WPF (.NET 8) — всё нужное в одном месте, без лишней возни 🎮

## ✨ Что умеет

- 📦 **Сборки под рукой** — создавайте и переключайте инстансы Minecraft в пару кликов
- 🔍 **Поиск модов** — интеграция с Modrinth и CurseForge прямо в лаунчере
- ⚙️ **Все загрузчики** — Forge, Fabric, Quilt и NeoForge
- ⬇️ **Умная загрузка** — версии, библиотеки и ассеты качаются автоматически
- ☕ **Автоподбор Java** — лаунчер сам находит подходящую JDK
- 🚀 **Быстрый запуск** — один клик, и вы в игре
- 🎨 **Приятный интерфейс** — тёмная тема, плавные анимации, ничего лишнего

## ⭐ Привилегии (донат)

Вкладка **«Привилегии»** в лаунчере. Все цены разовые (привилегия остаётся навсегда). У каждой привилегии есть свои уникальные функции:

| Привилегия | Цена | Что даёт |
|---|---|---|
| **Tadpole** | 50 ₽ | бейдж у ника, роль в Discord, тема **Mint**, **свой фон** лаунчера |
| **Froglet** | 150 ₽ | всё из Tadpole + тема **Sunset**, **авто-бэкап миров** перед запуском, **статистика игры** |
| **Frog+** | 300 ₽ | всё из Froglet + тема **Aurora**, **авто-обновление модов**, **быстрая загрузка** (16 потоков), **профили модов** |
| **Frog Legacy** | 700 ₽ | всё из Frog+ + тема **Gold** и золотой бейдж, **свой текст статуса Discord**, **бета-версии** лаунчера |
| **Admin** | — | выдаётся только вручную: все функции + **панель администратора** (список выданных привилегий) |

**Как купить** (то же написано в самом лаунчере): нажать «Купить» у нужной привилегии → откроется наш Discord, а текст заявки сам скопируется в буфер → вставить его в **личные сообщения поддержке** («Здравствуйте! Хочу купить привилегию <название>. Мой ник в Minecraft: <ник>. Тип аккаунта: Microsoft или Offline.») → поддержка подскажет оплату и поможет со всем. Всем купившим в Discord выдаётся **роль с названием привилегии**.

**Как выдать привилегию (для вас):** запустите `NewsPublisher.exe` → **5 — Выдать привилегию** (ник, уровень, срок), **6 — Отозвать**, **7 — Список**. Привилегии хранятся в `privileges.json` рядом с `news.json` и подхватываются лаунчером за ≤3 минут (или кнопкой «Обновить статус»). Привязка по умолчанию — к **UUID Microsoft-аккаунта** (подделать нельзя); для оффлайн-игроков привязка к нику (ник в оффлайне подделать можно — это ограничение любого лаунчера без своего сервера). Роль в Discord выдаёте вручную.

# 🛠 Для разработчиков

## Сборка (один раз)
1. Установите [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).
2. **Скопируйте `keys.props.example` в `keys.props` и заполните** (см. ниже) — тогда пользователям ничего настраивать не придётся.
3. Запустите `build.bat`. В папке `dist` появится:
   - **`FrogLauncherSetup.exe`** — установщик, его вы и раздаёте (лаунчер внутри);
   - `NewsPublisher.exe` — консоль для новостей (только для вас).

Без SDK: залейте папку в GitHub → вкладка *Actions* → *Build FrogLauncher* (ключи можно положить в Secrets: `CURSEFORGE_KEY`, `MS_CLIENT_ID`, `NEWS_URL`).

## Что делает установщик
Мастер в стиле лаунчера: Приветствие → Папка → Установка → Готово. Ставит в `%LocalAppData%\Programs\FrogLauncher` (права администратора не нужны), создаёт ярлыки **«FrogLauncher»** на рабочем столе и в «Пуск» — у ярлыков Windows никогда не показывает расширение, так что `.exe` на рабочем столе не видно. Запись в «Приложения и возможности»: удаление через неё или `FrogLauncher.exe --uninstall`.

## Ключи, «зашитые» в лаунчер (keys.props)
| Что | Зачем | Где взять |
|---|---|---|
| `CurseForgeKey` | каталог и сборки CurseForge | бесплатно: https://console.curseforge.com/ |
| `MsClientId` | вход через Microsoft | Azure → App registrations → New registration → *Personal Microsoft accounts only* → Authentication → *Allow public client flows = Yes*; затем заявка Mojang: https://aka.ms/AppRegInfo |
| `NewsUrl` | новости лаунчера | пишет сам `NewsPublisher` |
| `DiscordUrl` | **кнопка Discord в лаунчере** — ваша ссылка-приглашение (https://discord.gg/…) | ваш сервер Discord |
| `DiscordAppId` | статус в Discord «Играет в FrogLauncher» | https://discord.com/developers/applications → New Application (назовите **FrogLauncher**) → Application ID. В Rich Presence → Art Assets можно загрузить картинку с ключом `frog` |
| `UpdateRepo` | проверка обновлений (owner/repo) | необязательно |

Modrinth работает без ключа. Вшитые ключи лежат в exe — это обычная практика для лаунчеров; у пользователей есть необязательные поля «Дополнительно» в настройках.

## Новости лаунчера
Запустите `NewsPublisher.exe` → при первом запуске вставьте GitHub-токен (галочка *gist*) → **«1 — Добавить новость»**: пишете заголовок и текст **по-русски**, английский перевод делается автоматически (можно поправить), новость публикуется и появляется в лаунчере на русском и английском (обновление до 3 минут или кнопка ⟳). Ссылка на `news.json` записывается в `keys.props` (нужна одна пересборка лаунчера).

## Возможности лаунчера
- Первый запуск: экран входа (оффлайн-ник или Microsoft).
- «Мои версии»: RAM, JVM, разрешение, Java, сервер для автозахода, команды до/после игры, клон, бэкап миров, ярлык версии на рабочий стол, проверка файлов, учёт времени игры.
- Каталог версий: Fabric, Forge, Quilt, NeoForge; автоустановка Java.
- Каталог модов: Modrinth + CurseForge, зависимости, обновление модов, включение/выключение.
- Сборки: импорт/экспорт `.mrpack`, CurseForge `.zip`, собственный `.zip`.
- Настройки: скрывать лаунчер после запуска (или закрывать), открывать снова после выхода из игры, автозапуск с Windows, консоль игры, язык RU/EN, 3 темы, прокси.
- Вкладка «Моды версии» (название и картинка мода, переключатели вкл/выкл), «О приложении», статус в Discord.

## Где что лежит
- Данные лаунчера: `%AppData%\.froglauncher` (настройки, зашифрованная сессия, логи).
- Игра: `%AppData%\.froglauncher\game`.

## Структура
`Core/` (ApiConfig, BuiltIn, Loc, Shortcut, Uninstall…) • `Models/` • `Services/` • `ViewModels/` • `Views/` • `Setup/` (установщик) • `tools/NewsPublisher/` (консоль новостей).

## Внешние API
Mojang (piston-meta, libraries, resources, sessionserver), Fabric/Quilt Meta, Forge/NeoForge Maven, Adoptium, Microsoft/Xbox/Minecraft Services, **Modrinth API v2**, **CurseForge API v1**, mclo.gs, GitHub Gist API и MyMemory (перевод новостей, только в NewsPublisher).
