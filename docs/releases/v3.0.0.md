# 🐸 Ribbix Launcher 3.0.0

Самое большое обновление лаунчера: игра быстрее, с друзьями проще, а моменты из игры — сразу в TikTok.

## Кто вы?

### 🐸 Пользовались FrogLauncher
Ничего делать не нужно — **FrogLauncher обновится сам** и станет Ribbix Launcher:
- версии, миры, аккаунты, скины и статистика переедут из `%AppData%\FrogLauncher` в `%AppData%\RibbixLauncher` при первом запуске;
- старая программа, ярлыки и запись в «Программах» удалятся, ваши миры — нет;
- старые ссылки `froglauncher://` продолжат работать.

Если автообновление не пришло — скачайте **`RibbixLauncherSetup.exe`** ниже и установите поверх, данные перенесутся так же.
Файл `FrogLauncherSetup.exe` в этом релизе нужен только для автообновления старых версий — скачивать его вручную не надо.

### 🆕 Впервые с Ribbix
1. Скачайте **`RibbixLauncherSetup.exe`** ниже (Windows 10/11, 64 бит).
2. Запустите — права администратора не нужны, Java лаунчер поставит сам.
3. Войдите через Microsoft или играйте оффлайн, выберите версию в «Каталоге» и нажмите «Играть».

Дальше лаунчер будет обновляться сам.

## Что нового в 3.0

- **🚀 Ускорить** — одна кнопка ставит моды оптимизации под вашу версию: Sodium (Embeddium на Forge), Lithium, FerriteCore, ImmediatelyFast, EntityCulling, ModernFix, Dynamic FPS. Перед этим лаунчер сохраняет снимок модов — откатиться можно в любой момент.
- **🩺 Проверка перед запуском** — до старта игры лаунчер находит моды не для того загрузчика или версии Minecraft, нехватку зависимостей, дубликаты и мало памяти, и предлагает исправить.
- **🌍 Мир друзьям** — откройте свой мир для сети, и лаунчер даст адрес, по которому друзья зайдут через интернет. Без проброса портов и Hamachi. В Discord появится кнопка «Присоединиться».
- **🔄 Общая сборка** — поделитесь сборкой ссылкой, и у друзей она будет обновляться сама: добавили мод — он появится у всех, убрали — исчезнет. Друзьям аккаунт GitHub не нужен.
- **🗺 Карта мира** — вид сверху на любой ваш мир прямо в лаунчере, с вами и точкой спавна.
- **📜 Задания дня** — три задания каждый день, опыт и уровни. На 5 и 10 уровне открываются новые темы оформления.
- **🎬 Клипы для TikTok** — нажмите в игре Win+Alt+G (Xbox Game Bar), и лаунчер сделает из последних 30 секунд вертикальное видео 1080×1920 с логотипом.
- Переводы на English, Español, Deutsch и Português (BR) — полностью.
