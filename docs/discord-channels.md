## ❓-faq

```
# ❓ Частые вопросы

**Это бесплатно?**
Да. Игра запускается на любом тарифе. Подписка (Ribbix Lite / Ribbix+ / Pro / Legend) — только функции лаунчера: без рекламы, больше версий, темы, облачные бэкапы.

**Нужна лицензия Minecraft?**
Можно войти через Microsoft (лицензия) или играть с оффлайн-ником.

**Где скачать?**
Только здесь: https://github.com/lagushka594/Ribbix_Studio/releases/latest — файл `RibbixLauncherSetup.exe`. С других сайтов не качай!

**Это вирус? Windows ругается.**
Нет — лаунчер новый и пока без цифровой подписи, поэтому SmartScreen предупреждает. Нажми «Подробнее» → «Выполнить в любом случае». Весь код открыт на GitHub.

**Как поставить моды?**
Меню «Моды» → раздел «Моды» → выбери версию → «Установить». Зависимости (Fabric API и т. п.) ставятся сами.

**Как поставить скин?**
Вкладка «Скины» → «Из файла PNG» или «Взять по нику» → «Надеть». С лицензией скин видят все.

**Игра вылетает!**
Открой главную — «Доктор крашей» объяснит причину и предложит починку в один клик. Не помогло — #частые-ошибки.

**Я играл во FrogLauncher — что с моими мирами?**
Всё переносится само: просто поставь Ribbix, версии, миры и аккаунты переедут.
```

## 🚀-как-начать

```
# 🚀 Как начать играть за 2 минуты

**1. Скачай установщик**
👉 https://github.com/lagushka594/Ribbix_Studio/releases/latest
Файл — `RibbixLauncherSetup.exe`. Права администратора не нужны.

**2. Установи**
Запусти файл → «Далее» → «Установить». Если Windows предупредит — «Подробнее» → «Выполнить в любом случае».

**3. Войди**
«Профиль» → «Войти через Microsoft» (лицензия) или просто введи **оффлайн-ник**.

**4. Выбери версию**
«Каталог» → «+ Добавить» → версия Minecraft и модлоадер (Fabric, Forge, NeoForge, Quilt или без модов).
Или сразу готовую сборку: «Моды» → «Сборки».

**5. Жми ▶ ИГРАТЬ**
Лаунчер сам скачает игру, Java и всё нужное.

✨ **Фишки, которые стоит попробовать**
• 📈 «Замерить FPS» — лаунчер подберёт графику под твой ПК
• 👫 «С другом» — ссылка, по которой у друга сам поставится тот же Minecraft с модами
• 🎁 «Мой год» — итоги года карточками для сторис
• 🩺 «Доктор крашей» — чинит вылеты в один клик
```

## ⚠️-частые-ошибки

```
# ⚠️ Частые ошибки и решения

**🩺 Игра вылетела** — открой главную: «Доктор крашей» покажет причину и кнопку починки.

**«Не хватает мода …»** — нажми «Скачать» у Доктора. Fabric-моды почти всегда требуют **Fabric API**.

**«… не работает на 1.21»** — мод под другую версию игры. «Обновить» у Доктора или выключи мод.

**«Нужна Java 21»** — «Скачать Java 21» у Доктора, лаунчер сам её поставит.

**OutOfMemoryError / не хватает памяти** — «Дать N ГБ» у Доктора или «Каталог» → версия → «Производительность» → больше RAM.

**Чёрный экран / GLFW error 65542** — обнови драйвер видеокарты (NVIDIA / AMD / Intel).

**Непонятно, какой мод виноват** — «🔎 Найти мод-виновника»: лаунчер сам найдёт его за несколько запусков.

**Сломалось после «Обновить всё»** — «↩ Вернуть моды как было».

**Windows не даёт запустить установщик** — «Подробнее» → «Выполнить в любом случае».

Не помогло? Нажми «Загрузить на mclo.gs» и кинь ссылку сюда — поможем 🐸
```
