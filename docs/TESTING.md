# Чек-лист тестирования FrogLauncher

Пункты с меткой **[авто]** проверяются тестами `dotnet test FrogLauncher.sln`:
сквозные сценарии через HTTP API с управляемым временем — `tests/Frog.Api.Tests/SubscriptionFlowTests.cs`,
лаунчер — `tests/FrogLauncher.Tests`. Пункты **[руками]** требуют реальной платёжки/песочницы или UI.

Стенд: `Frog.Api` с тестовыми ключами YooKassa (тестовый магазин) или Paddle Sandbox (`Paddle:ApiBase=https://sandbox-api.paddle.com/`).

| 4 | **Даунгрейд после окончания** | [авто] `Downgrade_to_tadpole_after_canceled_period_ends`; [руками] «Управлять» → «Отключить автопродление» | До конца периода фичи остаются («Автопродление отключено · доступ до …»), после — Tadpole без grace |

| 7 | Идемпотентность и подлинность вебхуков | [авто] `Webhook_is_idempotent_and_requires_authenticity`, `Paddle_signature_is_verified_and_replay_rejected`, `YooKassa_ip_allowlist` | Повтор не продлевает срок дважды; поддельный/старый вебхук → 401 |
| 8 | Цены только с сервера, admin скрыт | [авто] `Tiers_endpoint_hides_admin…`, `Prices_are_within_rules`, `Invalid_price_fails_fast` | `/tiers` — 5 тиров без admin; API не стартует с ценой вне 50–700 ₽ |

| # | Сценарий | Как проверить | Ожидание |
