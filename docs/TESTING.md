# Чек-лист тестирования FrogLauncher

Пункты с меткой **[авто]** проверяются тестами `dotnet test FrogLauncher.sln`:
сквозные сценарии через HTTP API с управляемым временем — `tests/Frog.Api.Tests/SubscriptionFlowTests.cs`,
лаунчер — `tests/FrogLauncher.Tests`. Пункты **[руками]** требуют реальной платёжки/песочницы или UI.

Стенд: `Frog.Api` с тестовыми ключами YooKassa (тестовый магазин) или Paddle Sandbox (`Paddle:ApiBase=https://sandbox-api.paddle.com/`).
