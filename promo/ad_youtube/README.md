# Рекламная интеграция для YouTube

16:9, 1920×1080, 30 fps, ~2:18. Итог: `out/ribbix_ad_16x9.mp4`.
Слева — заголовок блока и пункты под голос, справа — экран лаунчера. В углу — метка «Реклама».

Блоки: интро → версии и загрузчики (+ Java, знакомство) → моды и зависимости → настройки и «Подобрать под мой ПК» →
серверы → статистика, достижения, бейджи → миры: автобэкап, восстановление, экспорт/импорт → сезонные темы →
Ctrl+K, трей и напоминание, карточки скриншотов, Discord, 5 языков → CTA.
Всё названное есть в README лаунчера (разделы «Лаунчер», v2.1–v2.5).

Текст озвучки — `LINES` в `tts_neural.py`. Длина блоков считается от длины реплик, голос не ускоряется.

| Файл | Что делает |
|---|---|
| `tts_neural.py` | мужская озвучка (Dmitry Neural, edge-tts, нужен интернет); готовые строки пропускает, `--force` — перезаписать |
| `ad.py` | покадровый рендер; мокапы вкладок — из `../scenario3,4,5,7/render.py` |
| `mix.py` | бит 120 BPM из `../scenario3/mix.py` (16%), SFX на пунктах и переходах, озвучка |

```bash
python tts_neural.py
python ad.py
python mix.py
ffmpeg -i out/video_noaudio.mp4 -i out/audio_mix.wav -af loudnorm=I=-14:TP=-1.5 -c:v copy -c:a aac -b:a 192k -shortest out/ribbix_ad_16x9.mp4
```

Важно перед публикацией:
- онлайн и пинг серверов в мокапе — условные цифры (сами серверы взяты из `servers.json`); в лаунчере они живые;
- реклама в РФ маркируется: «Реклама», рекламодатель и токен erid — в ролике есть только метка, остальное добавьте
  в описание/кадр по требованиям ОРД.
