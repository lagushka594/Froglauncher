# Промо «Статистика игрока» (сценарий 7)

9:16, 1080×1920, 30 fps, 28,85 с. Итог: `out/ribbix_stats_9x16.mp4`.

Мокап «Профиль → 📊 Статистика» (`Views/ProfileView.xaml`, `StatsViewModel`): бейдж и «До «Легенда» 👑 осталось …»,
плитки, график за 14 дней, «В мирах Minecraft», «Любимые версии». Пороги бейджей — `PlayStatsService.Badges`
(Новичок 0+, Опытный 10+, Ветеран 100+, Легенда 500+ ч). Цифры игрока вымышленные.

Всё показанное есть в лаунчере (README, раздел v2.2 «Погружение»): список достижений с прогрессом
(122 в 1.21, «Только невыполненные»), плитка «последняя игра», часы и сессии каждой сборки в «Любимых версиях».
Отличие только в раскладке: в мокапе список достижений открывается поверх плитки, в лаунчере он ниже на странице.

| Файл | Что делает |
|---|---|
| `tts_neural.py` | мужская озвучка (Microsoft Dmitry Neural, edge-tts, нужен интернет) → `audio/vt_N.wav` |
| `render.py` | покадровый рендер → `out/video_noaudio.mp4`; хелперы — из `../scenario3/render.py` |
| `mix.py` | чилл-подложка из `../scenario4/mix.py` (25%), SFX из `../scenario3/mix.py`, озвучка → `out/audio_mix.wav` |

```bash
python tts_neural.py
python render.py
python mix.py
ffmpeg -i out/video_noaudio.mp4 -i out/audio_mix.wav -af loudnorm=I=-14:TP=-1.5 -c:v copy -c:a aac -b:a 192k -shortest out/ribbix_stats_9x16.mp4
```

Тайминг (сдвинут под озвучку — реплики ~35 с при плане 25): 0–4.15 крючок · 4.15 часы и сессии ·
9.6 достижения · 15.3 бейдж · 22.27 график · 25.88–28.85 CTA.
